# Web GIS Pemetaan Fasilitas Umum Kota Solok

Proyek ini merupakan aplikasi Web GIS yang menampilkan persebaran fasilitas umum di Kota Solok menggunakan data OpenStreetMap.

## Fitur

- Peta interaktif
- Marker Cluster
- Popup informasi fasilitas
- Zoom dan Pan
- Basemap OpenStreetMap

## Teknologi

- Python
- Folium
- OpenStreetMap
- Leaflet.js

## Cara Menjalankan

Cukup buka:

index.html

atau akses melalui GitHub Pages.

## Dataset

Data diambil dari OpenStreetMap menggunakan library OSMnx.
